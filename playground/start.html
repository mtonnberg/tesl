From checked source to a real response

Make your first request.

Start with a small HTTP server you can read in a minute. No database service or account is needed for this example.

1. Install Tesl

Tesl is beta. Follow the current installation guide for your system, then confirm tesl help works. The installation guide is the authority on supported methods.

Using a coding agent? Copy a setup prompt

Paste this into a coding agent with terminal access. It asks the agent to follow current installation guidance and verify a real response.

2. Save the server

Download HelloServer.tesl into a new directory. It declares GET /hello, its handler, and an App using port 8086. You can also pick “Hello HTTP” in the playground and choose “Save .tesl”.

3. Check it, then run it

tesl check HelloServer.tesl
tesl run HelloServer.tesl

Leave that terminal running. In another terminal:

curl http://localhost:8086/hello

You should get an HTTP 200 response containing Hello from Tesl!. Stop the server with Ctrl+C. The playground checks the same source but does not start the server.

4. Build something of your own

Change the greeting and run again. When you want a project structure, use tesl init myapi and follow the quick start. The first-change guide walks through a small change in a real project.

Curious about the invoice example? Its fact names a rule, the check validates it, and the receiving function requires that evidence. Select a keyword and choose “Explain this” in the playground. Short lessons are there when you need them.
