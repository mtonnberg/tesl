        This page runs the real Tesl compiler (parser, type checker, proof
        checker, validation, linter, emitters) compiled to JavaScript. It works
        on one buffer, so an import of another local module
        cannot resolve — stdlib Tesl.* imports are compiled in.
        Nothing you type leaves the browser: the share link carries the source in
        the URL fragment, which is never sent to a server.
