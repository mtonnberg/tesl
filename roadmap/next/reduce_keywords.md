# Language simplification

## Background

## Goal

- To have as easy-to-learn language as possible while providing all the benefits that Tels aims to offer.
- A user that have learnt one pattern can extrapolate it and more easily learns the next concept/pattern.

## Open questions

- Can we reduce the number of keywords by leveraging normal types/records instead? That would also make the language more discoverable and allow for easy hints via the compiler etc
- Can we improve the error messages in general (making them more helpful/specific)
- Can we add make the LSP/MCP/vscodium extension much more powerful? (making many more actions autocompletable/autofixable for instance)
