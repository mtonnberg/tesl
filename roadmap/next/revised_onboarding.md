# Revised onboarding

## Background

We have a lot of documentation that (as far as I know) is up to date. But it makes it difficult for newcomers to start (users and new maintainers alike).

## Goal

- When an interested person asks for a link the maintainers should have one good link to send them
- The onboarding should be crisp, welcoming, helpful and not verbose (same for all documentation)

## Notes

- This will probably require quite a reshuffling of the current docs/lessons/readme/language-spec etc
- Maybe it is time to revisit the online editor (it would be awesome to have a homepage listing all the lessons and you can run it directly there). Also it would be a good way to share Tesl-code.
- LLM like a lot of documentation but we need to ensure that the human readers also can use the system.
